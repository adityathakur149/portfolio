# Aditya Thakur — Personal Portfolio

A responsive personal portfolio website showcasing projects, skills, education, and contact information.

## Highlights
- Modern dark-themed UI with glassmorphism accents and smooth animations
- Responsive layout (mobile, tablet, desktop)
- Project showcase featuring DevCollab, StudyBuddy AI, Portfolio, and SkyFlow
- Fast, static site (HTML/CSS/JS) with no heavy framework dependencies

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome

## Files
- `index.html` — Page structure and content
- `style.css` — Styling and design system
- `script.js` — Interactions (typing effect, scroll reveal, navigation)

## Run Locally
Open `index.html` in your browser, or serve the folder with any static server (e.g., VS Code Live Server).

## Deploy
This site is ready for GitHub Pages. Push the `portfolio/` contents to a repo and enable Pages.
