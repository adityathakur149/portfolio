BIS Compliance Copilot

An auditable AI compliance assistant for Indian Standards (BIS) with split-screen UI: conversational Q&A copilot (left) and PDF viewer (right) that auto-navigates to cited clauses when references are clicked.

Problem

Compliance professionals need to quickly find and verify specific clauses in dense BIS standard documents.

Solution

React + FastAPI app with RAG pipeline: PyMuPDF parsing → text chunking → ChromaDB embeddings → Google Gemini 2.0 Flash for structured answers with page-level citations. Click citation badges to jump to exact PDF page.

Architecture

User → React Chat → FastAPI /api/chat → ChromaDB retrieve → Gemini generate → JSON with citations → PDF viewer auto-navigate to page.

React FastAPI ChromaDB Google Gemini PyMuPDF Tailwind CSS
GitHub

StudyBuddy AI

A RAG-powered study assistant that ingests PDFs, performs semantic retrieval with ChromaDB and sentence-transformer embeddings, and answers questions with citations to retrieved source passages.

Problem

Students struggle to extract answers from dense PDFs efficiently.

Solution

FastAPI backend with document ingestion, chunking, embedding generation, and semantic retrieval via REST endpoints. Context-aware answer generation with source citations.

Architecture

PDF parsing → Text chunking → all-MiniLM-L6-v2 embeddings → ChromaDB vector store → Semantic search → LLM answer generation with citations.

Testing & Limitations

Evaluated on custom question sets; citation accuracy varies with chunk size. Math-heavy PDFs parse poorly with PyMuPDF.

DevCollab

A room-based collaborative code editor with shared editing, participant presence, in-room chat, and sandboxed code execution across 10+ languages via Wandbox.

Problem

Remote pair programming lacks real-time synchronization and integrated execution environments.

Solution

React + Monaco Editor frontend with Socket.io for real-time sync (operational transforms), presence, and chat. Node.js/Express backend with JWT auth and MongoDB persistence.

Architecture

WebSocket rooms → Monaco Editor bindings → Shared cursor/selection state → Wandbox API for execution → JWT-protected REST for projects/auth.

Security Note

Code execution security relies on Wandbox's sandbox isolation. JWT authentication handles application-level access control only.

React Node.js Socket.io MongoDB Monaco Editor
